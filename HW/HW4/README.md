## 關於本書

本書由 AI 生成，內容涵蓋系統程式的各個面向，包含：

- CPU / ISA 設計原理
- 組譯器、編譯器、連結器實作概念
- 作業系統核心設計（行程、記憶體、檔案系統）
- 中斷、系統呼叫、虛擬化
- 搭配 ccc 的 cpu2os 教材，理論與實作並重

適用對象：修習系統程式課程的學生、對計算機底層有興趣的開發者。
